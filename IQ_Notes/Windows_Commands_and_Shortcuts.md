# Basic Commands and Shortcuts for Windows

## 1. Windows Command Prompt Commands
- `dir` - Show files and folders in the current directory
- `cd` - Change directory
- `cd ..` - Go to the parent folder
- `mkdir foldername` - Create a new folder
- `rmdir foldername` - Remove an empty folder
- `copy file1 file2` - Copy a file
- `move file1 file2` - Move a file
- `del filename` - Delete a file
- `ren oldname newname` - Rename a file or folder
- `type filename` - View the contents of a file
- `notepad filename` - Open a file in Notepad
- `cls` - Clear the command screen
- `help` - Show available commands
- `ipconfig` - Show network details
- `ping website.com` - Test network connection

## 2. File Handling Commands in Windows
- `echo text > file.txt` - Create or overwrite a file with text
- `echo text >> file.txt` - Append text to an existing file
- `type nul > newfile.txt` - Create a new empty file
- `copy file1.txt file2.txt` - Copy one file to another file
- `xcopy source destination /E` - Copy folders and subfolders
- `del file.txt` - Delete a file
- `rename oldname.txt newname.txt` - Rename a file
- `move file.txt folderile.txt` - Move a file into a folder

## 3. Basic Git Commands
- `git init` - Start a new Git repository
- `git clone <url>` - Copy a repository from GitHub
- `git status` - Check changes
- `git add .` - Add all changes
- `git commit -m "message"` - Save changes with a message
- `git push` - Upload changes to GitHub
- `git pull` - Download latest updates
- `git branch` - Show branches
- `git checkout <branch>` - Switch branches
- `git log --oneline` - View recent commits

## 4. Useful Windows Shortcuts
- `Ctrl + C` - Copy
- `Ctrl + V` - Paste
- `Ctrl + X` - Cut
- `Ctrl + Z` - Undo
- `Ctrl + Y` - Redo
- `Ctrl + A` - Select all
- `Ctrl + F` - Find text
- `Ctrl + H` - Replace text
- `Alt + Tab` - Switch between open apps
- `Windows + E` - Open File Explorer
- `Windows + D` - Show desktop
- `Windows + L` - Lock your PC
- `F2` - Rename a selected file or folder
- `Delete` - Move selected item to Recycle Bin

## 5. VS Code Shortcuts for Files and Editing
- `Ctrl + N` - Create a new file
- `Ctrl + Shift + N` - Open a new VS Code window
- `Ctrl + S` - Save the current file
- `Ctrl + Shift + S` - Save As
- `Ctrl + W` - Close the current file
- `Ctrl + P` - Open a file quickly
- `Ctrl + Shift + P` - Open Command Palette
- `Ctrl + ` ` - Open terminal
- `Ctrl + /` - Comment or uncomment code
- `Shift + Alt + A` - Toggle block comment
- `Ctrl + F` - Find in the current file
- `Ctrl + H` - Replace text in the current file
- `Ctrl + Shift + B` - Run build task

## 6. Comment Shortcuts
- `Ctrl + /` - Add or remove single-line comments
- `Shift + Alt + A` - Add or remove block comments
- Use comments to explain code, mark TODOs, and describe steps

## 7. Quick Notes
- Use `git status` often to see what changed
- Always commit with a clear message
- Use `git pull` before pushing new work
- Use `Ctrl + S` often to save your file updates
- Use `Ctrl + N` to create a new file when starting something new
