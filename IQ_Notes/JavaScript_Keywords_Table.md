# JavaScript Keywords

JavaScript keywords are reserved words that have special meanings in the language. They are used to define syntax, control program flow, declare variables, and handle errors.

| Category | Keywords |
|---|---|
| Declaration | var, let, const |
| Function | function, return |
| Conditional | if, else, switch, case, default |
| Loop | for, while, do, break, continue |
| Exception Handling | try, catch, finally, throw |
| Class / Object | class, extends, new, this, super |
| Module / Import | import, export |
| Variable / Scope | void, yield, await |
| Type / Value | instanceof, typeof, in |
| Reserved / Special | debugger, with |
| Value / Null | null |
| Delete / Remove | delete |
